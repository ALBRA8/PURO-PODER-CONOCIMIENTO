# SECCIÓN 1: EXPONENTIAL MARKETING

## Mental - El Algoritmo

**Loop de 6 pasos:**
1. **Contemplación** - Observar sin juzgar
2. **Intención** - Decidir qué lograr
3. **Era Eléctrica** - Generar ideas con IA
4. **Sísifo** - Ejecutar sin esperar motivación
5. **Einstein** - Aprender de errores
6. **Repetir** - Ciclo continuo

**Decisiones irreversibles:** Emprender, vender casa, casarse  
**Opciones reversibles:** Qué vender, supply chain, empleados

**Personaje vs Individual:**
- Personaje = quién ERES en público
- Individual = versión privada
- Holding requiere múltiples personajes

# SECCIÓN 2: CHAT MARKETING
## Modelo 360° (4 Módulos)

### Módulo A: Investigación + Posicionamiento

- Arquetipo de Marca
- Genética de Marca

### Hofstede - Dimensiones Culturales
| Dimensión | Significado |
|-----------|-------------|
| PDI | Distancia al poder |
| IDV | Individualismo vs Colectivismo |
| MAS | Masculinidad vs Feminidad |
| UAI | Evitación incertidumbre |
| LTO | Orientación largo plazo |

**Ejemplo:** Austria bajo IDV (yeite individual) → marketing conecta aspiraciones personales, no grupo. Latinoamérica alto IDV → marketing funciona por imitación.

### Código Simbólico (Rapaille)
Las "improntas" = conexión emocional temprana.
- USA: Jeep = "CABALLO" (libertad)
- Europa: Jeep = "LIBERADOR" (WWII)

### USP - Propuesta Única de Valor
**Estructura:** [Beneficio único] + [Para quién] + [Resultado específico]

**Ejemplos:**
- Coca-Cola: "Open Happiness"
- BMW: Estatus + logro
- McDonald's: Quality, Service, Cleanliness, Value

**Míos (144 chars):**
1. "Domina el arte de vender con IA: estrategias probadas para emprendedores ambiciosos que quieren resultados sin sacrificar tiempo."
2. "Construye un holding 1-persona con IA: un solo operario, sistemas infinitos, ganancia exponencial."

### Jobs to be Done
Clientes contratan SOLUCIONES, no productos.
- McDonald's: "Sacian hambre medianoche cuando otros cerrados"
- Agencia inglés: Contratan "fluidez para mejor trabajo"
- iPhone SE: Contratan "ser parte de Apple"

# SECCIÓN 3: ESPIONAJE VIRAL

## Los 4 Pilares (4Fs de CÓDICE)

| Pilar | Pregunta | Uso |
|-------|----------|-----|
| **Feeding** | ¿Qué alimenta al nicho? | Contenido que consume |
| **Fighting** | ¿Contra qué lucha? | Dolores a resolver |
| **Fleeing** | ¿De qué huye? | Miedos a eliminar |
| **Reproduction** | ¿Cómo se reproduce socialmente? | Forma de compartir |

## Productos Extranjeros Virales (P.E.V.)

**Proceso:**
1. Encontrar productos que venden en USA/Europa
2. Adaptarlos a LATAM antes que competencia
3. **Ventaja:** 6-12 meses head start

**Ejemplo:**
- USA: Producto X vendiendo $1M/mes
- LATAM: Nadie lo vende
- Acción: Importar/adaptar primero

## Herramientas de Espionaje

| Herramienta | Tipo | Uso |
|-------------|------|-----|
| Meta Ad Library | Gratis | Ver anuncios activos de competencia |
| AdSpy | Pago | Anuncios históricos, engagement |
| AdSparo | Pago | Filtrar por país, categoría |
| BigSpy | Pago | Trending ads, viralidad |

## Modelado de Anuncios

**Pasos:**
1. Identificar top performers (likes + comments altos)
2. Descomponer estructura: Hook → Cuerpo → CTA
3. Re-crear con tu producto
4. A/B testear variantes

# SECCIÓN 4: CREAR MODELOS CON VO3

## Sistema: 6 Pasos

| Paso | Acción | Detalle |
|------|--------|---------|
| 1 | **Definición** | Responder 14 preguntas |
| 2 | **Generación** | Imagen ultrarrealista |
| 3 | **Memorización** | ChatGPT guarda características |
| 4 | **Prompt Base** | Formato consistente |
| 5 | **Producción** | 8s con Veo 3 |
| 6 | **Viralización** | Publicar + engagement |

## Las 14 Preguntas del Personaje

1. Nombre
2. Piel (tono, textura)
3. Ojos (color, forma)
4. Cabello (color, estilo, largo)
5. Cuerpo (complexión)
6. Estilo (ropa, accesorios)
7. Edad aparente
8. Personalidad
9. Acento
10. Jerga
11. Referencias
12. Trauma/pasado
13. Percepción deseada
14. Arquetipo

## Formato Prompt Veo 3

```
Escena: [ubicación]
Hora: [día/noche]
Iluminación: [cinemática/neón/natural]
Cámara: [encuadre] [movimiento]
Personaje: [nombre] + características
Expresión: [emoción]
Lenguaje corporal: [postura]
Audio: [idioma/acento] "[diálogo]"
Tiempo: 8 segundos (2+4+2)
Estilo: Vertical 9:16
```

# SECCIÓN 5: SISTEMAS BOOTSTRAP (Extraído)

## Válvula Patrón

Sistema de control de flujo:
- **Entrada:** Clientes, leads
- **Válvula:** Criterios de filtro
- **Salida:** Acción específica

**Ejemplo:** Si cliente paga X → válvula abre → acceder a Y.

## Outsourcing con IA

**Proveedores de 3ros:**
- Un proveedor = punto único de fallo
- Diversificar o tener Plan B
- Documentar procesos para replicabilidad

## Automatización
**Principio:** Automatizar ANTES de escalar.

## PROMPTS EJECUTIVOS

### Buyer Persona Completo
```
Crea buyer persona para [PRODUCTO] incluyendo:
- Nombre ficticio
- Personalidad
- Necesidades funcionales vs emocionales
- Valores
- Canales de comunicación
- Comportamiento online
- Proceso de compra
- Miedos (lógico/psicológico/existencial)
- Deseos profundos
```

### USP Generator
```
Desarrolla USP para [PRODUCTO]:
- Beneficio único
- Diferenciación
- Resultado específico
- Máximo 144 caracteres
```

### Miedos y Soluciones
```
Lista miedos principales de [PRODUCTO], clasifica:
- Lógico (superficial)
- Psicológico (social)
- Existencial (profundo)
Dame soluciones específicas para cada uno.
```

### Jobs to be Done
```
Usando Jobs to be Done, dame 10 trabajos que clientes
quieren hacer contratando [PRODUCTO]. Selecciona 3 que
generen diferenciación. Diseña soluciones específicas.
```

### Código Simbólico
```
Basado en teoría Rapaille, dame hipótesis de "improntas"
emocionales para [CONCEPTO] en [PAÍS/MERCADO].
Identifica código cultural probable.
```

### Arquetipo de Marca
```
Determina arquetipo Jung para [MARCA] basado en:
- Personalidad
- Valores
- Comportamiento
- Mensajes públicos
Explica por qué ese arquetipo.
```

### Metáfora Zaltman
```
De las 7 metáforas (Equilibrio, Transformación, Viaje, Contenedor,
Conexión, Recurso, Control), ¿cuál es más adecuada para [PRODUCTO]
y por qué? Crea mensajes usando esa metáfora para [PÚBLICO OBJETIVO].
```

### Email Marketing (Secuencia 5 emails)
```
Escribe secuencia de 5 emails para [MODELO DE NEGOCIO]:
- Enfoque educativo (no venta directa)
- Contenido de alta calidad
- Ejemplos reales
- Actividades prácticas
- 1 CTA al final de cada email
- Estilo conversacional
```

### Contenido Social Media
```
Crea 10 ideas de contenido para [PLATAFORMA] sobre [TEMA].
Incluye: N°, Idea, Formato, Etapa funnel, Red social.
```

### SEO Blog Post
```
Artículo SEO sobre [TEMA/KEYWORD]:
- Palabra clave: [KEYWORD]
- Etapa buyer journey: [descubrimiento/consideración/decisión]
- 5 títulos H1 propuestos
- Estructura H2/H3 optimizada
```
